Grupo Élite Work

Política de Privacidad

Última actualización: 2 de mayo de 2026

En Grupo Élite Work nos comprometemos a proteger tu información personal. Esta política explica qué datos recopilamos, cómo los usamos y cómo los protegemos.

1. Información que recopilamos

  • Nombre completo
  • Número de teléfono y mensajes enviados a través de WhatsApp
  • Correo electrónico
  • Ciudad o ubicación
  • Información de disponibilidad y experiencia laboral
  • Datos de interacción con nuestros anuncios en Meta (Facebook e Instagram)

2. Cómo usamos tu información

  • Para contactarte en relación con oportunidades de empleo
  • Para gestionar tu proceso de reclutamiento y selección
  • Para enviarte información sobre webinars y eventos de capacitación
  • Para mejorar nuestras campañas publicitarias mediante Meta Pixel y Conversions API
  • Para agendar entrevistas y dar seguimiento a tu candidatura

3. Compartición de datos

No vendemos ni compartimos tu información personal con terceros, excepto con los siguientes proveedores de servicio necesarios para operar:

  • Meta Platforms — para publicidad y análisis (Facebook, Instagram, WhatsApp)
  • Google Firebase — para almacenamiento seguro de datos
  • Resend — para envío de correos electrónicos
  • Anthropic — para asistencia de inteligencia artificial en conversaciones

4. Meta Pixel y Conversions API

Utilizamos Meta Pixel y la API de Conversiones de Meta para medir la efectividad de nuestros anuncios. Los datos enviados a Meta (como número de teléfono y correo electrónico) se hashean con SHA-256 antes de ser transmitidos, de modo que Meta no recibe tu información en texto plano.

5. Retención de datos

Conservamos tu información durante el tiempo que sea necesario para los fines del proceso de reclutamiento, o hasta que solicites su eliminación.

6. Tus derechos

Tienes derecho a acceder, corregir o solicitar la eliminación de tu información personal en cualquier momento. Para ejercer estos derechos contáctanos en:

gonzalezluis@grupoelitework.com

7. Eliminación de datos

Si deseas que eliminemos todos tus datos de nuestros sistemas, envía un correo a gonzalezluis@grupoelitework.com con el asunto "Solicitud de eliminación de datos" y lo procesaremos en un plazo máximo de 30 días.

8. Contacto

Si tienes preguntas sobre esta política de privacidad, puedes contactarnos:
